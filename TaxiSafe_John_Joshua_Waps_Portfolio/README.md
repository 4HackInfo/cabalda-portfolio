# John Joshua Waps — TaxiSafe Portfolio

A responsive, one-page portfolio built with HTML, CSS, and vanilla JavaScript. It uses a distinct navy, cyan, and taxi-yellow visual identity and includes a profile image placeholder plus an original CSS illustration of the TaxiSafe concept.

## Before publishing
1. Replace `assets/profile-placeholder.jpg` with John's actual portrait photo (keep the same filename, or update the image path in `index.html`).
2. Update the skills/progress bars to match technologies John has actually used.
3. Replace the contact placeholder with his real email and professional links. The email button is intentionally not prefilled.
4. Review the TaxiSafe description against the final approved capstone scope.
5. Open `index.html` in a browser and test on mobile and desktop.

## Run locally
Double-click `index.html`, or open the folder in VS Code and use Live Server.

## Deploy to GitHub Pages
1. Create a repository and upload the contents of this folder to its root.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. Open the Pages URL shown by GitHub and test the site.
